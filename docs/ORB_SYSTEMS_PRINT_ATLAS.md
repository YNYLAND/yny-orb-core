# ORB SYSTEMS PRINT ATLAS

## Goal

Create a printable architecture atlas where the master sheet shows the whole Orb organism and every major system receives its own dedicated sheet.

## Sheet 0 — ORB SYSTEMS SYSTEM

Master skeleton of the organism:
- Flagship Orb Core at the center;
- all major systems around it;
- main data/action flows;
- Actor;
- external world boundary;
- State Delta loop;
- channel/render surfaces.

## Standard layout for each printed system sheet

Every sheet should use the same visual grammar.

### Header
- system number;
- English canonical name;
- Russian descriptive name;
- one-sentence purpose;
- development status.

### Center
Large central system node.

### Left side — Inputs
What enters this system.

### Right side — Outputs
What the system produces for other Orb systems.

### Top — Internal organs/modules
Major submodules or services.

### Bottom — Runtime flow
Step-by-step operational sequence.

### Footer — Current reality
Three columns:
- WORKING NOW;
- BUILDING NOW;
- PLANNED.

### Connections
Show only meaningful upstream/downstream links to other systems, using canonical system names.

## Special directional sheets

### Integration System
Primary direction:

```text
EXTERNAL WORLD
→ INTEGRATION SYSTEM
→ ORB ECOSYSTEM
```

Focus on inbound data, signals, files, events, normalization, provenance and permissions.

### Connector System
Primary direction:

```text
ORB / ACTION SYSTEM
→ CONNECTOR SYSTEM
→ EXTERNAL WORLD
```

Focus on outbound execution, external authentication, provider adapters, action support, errors/results and connection health.

These two sheets may share a small mirrored diagram showing that together they form Orb's world boundary.

## Naming canon

Use **Information System** as the umbrella architecture term.

Do not use `Infoteka System` as the umbrella because **INFOTEKA** is a specific Neo World module/product.

INFOTEKA may later appear inside Information System as one ingestion/structuring capability.

## Print canon

Preferred printable style:
- 4:3 landscape;
- white/light background;
- dark navy typography;
- one accent color per system;
- high contrast;
- minimal gradients;
- thin connection lines;
- no decorative text that competes with architecture;
- enough margins for physical printing;
- same numbering and color across every sheet.

## Atlas rule

The master sheet answers:

> What systems make Orb whole?

Each child sheet answers:

> How does this one organ work, what does it consume, what does it produce, and how developed is it now?
