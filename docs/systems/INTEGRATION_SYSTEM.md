# ORB INTEGRATION SYSTEM

## Purpose

Integration System governs the one-way transition by which a candidate object becomes a recognized part of the unified Neo World / Orb field.

It is not a connector, transport or external reader.

Canonical direction:

```text
CANDIDATE
→ INTEGRATION RULES
→ VALIDATE / NORMALIZE / MAP
→ ACCEPT OR REJECT
→ IF ACCEPTED: MANIFEST INSIDE NEO WORLD
```

## Core question

> Can this become part of Neo World, under what standards, in what canonical form, with what relations, visibility, authorship and rights?

## Candidate types

- Actor/profile representation
- project
- artifact/work/book
- knowledge block
- content
- method/service
- event/news item
- site
- organization
- place
- token/NFT
- world/space/game object
- external data obtained through Connector System

## First-stage interface

The current SYSTEM-mode Integration surface may begin as a simple:

```text
PLUS  — candidates to integrate / accepted direction
MINUS — rejected / excluded / not yet compatible
```

Later it can expand into passports, statuses, reasons, rules and graph manifestation.

## Target flow

```text
CANDIDATE

↓

```

## Outputs

Possible outputs after successful integration:
- entity
- entity passport
- content block
- graph relations
- Wiki presence
- Guide visibility
- searchable/indexed knowledge
- attribution / ownership
- monetization eligibility
- reusable content rights
- state delta + integration event

## Rejection / pending

Integration is not automatic.

Possible states:
- candidate
- validating
- needs_normalization
- needs_rights
- accepted
- rejected
- suspended
- deprecated

Rejection should preserve a reason and evidence.

## Relationships with other systems

### Connector System
Connector transports/reads/sends. Integration decides whether an imported candidate becomes part of Neo World.

### Information System
Information may exist as usable source material without being a shared Neo World entity. Integration promotes selected information into canonical shared forms.

### Entity / Relation / Graph System
Integration is a primary gate for creation of canonical entities and relations in the shared graph.

### Economy & Offer System
Integrated objects may later become eligible for paid reuse, royalties or other economic mechanics.

### State System
Successful integration creates a measurable state delta.

## Canonical rule

> Integration means becoming part of the whole.
